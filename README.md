# Aplikasi Stok Barang

Aplikasi desktop berbasis **Java Swing (NetBeans)** untuk mengelola data stok barang.

## 📌 Fitur
- Login pengguna
- Master data barang
- Barang masuk
- Barang keluar
- Laporan stok (JasperReport)

## 🛠️ Teknologi
- Java (Swing)
- NetBeans IDE (versi 8.2)
- MySQL
- JasperReport

## ▶️ Cara Menjalankan
1. Import project ke NetBeans
2. Import database MySQL
3. Atur koneksi database
4. Masukan file yg ada di file pendukung ke library netbeans 
5. Jalankan aplikasi
